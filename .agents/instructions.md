# Antigravity Instructions for HanziLearner

## General Behavior
- **Never start implementation (EXECUTION mode)** without explicit verbal consent from the USER in the chat.
- Approval of an implementation plan or a "LGTM" is **not** an instruction to start coding.
- Always ask "Should I proceed with the implementation now?" and wait for a direct confirmation (e.g., "Yes", "Proceed", "Start").
- Only proceed to EXECUTION mode if the USER explicitly instructs to do so.

## Planning
- Stay in PLANNING mode for research and design.
- Create or update design documents in the `designs/` folder.
- Present an implementation plan and wait for both approval of the plan AND a separate explicit instruction to start the work.
